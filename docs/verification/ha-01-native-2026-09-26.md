## Confirmed defects and candidate corrections

A deterministic local regression forces a blocked `thread/resume` request to
wake its worker during cancellation, before the cancel handler reacquires its
lock. The released broker reports failure. The candidate preserves the
cancellation already recorded by the broker and emits a single cancelled
result. It still reports genuine startup failures when cancellation was not
requested. Native acceptance of this candidate remains pending installation.

Six deterministic race cases also cover cancellation during the total deadline,
watchdog abort and runtime-generation reconciliation. The final locked state
owns the outcome; real provider completion and failure remain unchanged.

Separately, a real Integration setup and public HA service call reproduced stale
capabilities after an App upgrade. The candidate reuses the runtime's private,
throttled readiness refresh after authorisation, then checks the advertised
capability again. Older Apps remain rejected and denied users make no readiness
or task calls.

Windows Git checkout converted immutable stdio package sources to CRLF. Their
locked byte verification correctly refused staging. A targeted Git attribute
now preserves those source bytes as LF; staging and non-root image verification
pass without changing the package lock.

signature, provenance and SBOM verification. Supervisor and HACS installed

The native repeat passed start, continuation, idempotent retry, cancellation,

the tested result, without attributing the earlier timeout to an event-loss bug.

this fixture deliberately grants no host access. The superseded DEV Bridge
